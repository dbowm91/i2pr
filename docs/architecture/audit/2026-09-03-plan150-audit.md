# Plan 150 architecture and evidence audit

Date: 2026-09-03 (UTC)

## Result

Plan 150 closes the SAM 3.1 localhost application layer. The real
`sam_loopback_listener` was driven only through its TCP interface by two
independently implemented external clients. The lane passed exact binary
STREAM in both directions, `SILENT=true`, private-destination generation and
import, NAMING, unsupported-input rejection, multiple streams/lifecycle, and
loopback `STREAM FORWARD` with authenticated peer metadata.

The result is experimental, loopback-only, and non-advertised. It does not
claim public I2P, router-to-router NTCP2/SSU2, or mixed-router tunnel
interoperability.

No external source is vendored or patched for i2pr. The i2psam snapshot's
second-seeded session-ID generator is accommodated by one-second launch-slot
serialization in the harness, making the exact snapshot reproducible without
changing the client.

## Ownership correction

`STREAM FORWARD` now has a supervised per-session worker in
`i2pr-daemon`. `SamStreamRegistry::register_forward_attachment` owns a bounded
forwarding attachment without mutating the pending `ACCEPT` queue. The worker
accepts authenticated inbound streams, connects each to the already-validated
numeric loopback target, and reuses the raw byte driver and bridge under
cancellation. The control task's cancellation no longer tears down a raw
CONNECT/ACCEPT destination driver after socket handoff.

This preserves the architecture boundary: `i2pr-api` remains runtime-neutral;
Tokio sockets, tasks, timers, cancellation, and the local product directory
remain daemon-owned.

## Reproduction and evidence

```text
bash scripts/interop/fetch-sam-clients.sh --rebuild
bash tests/integration/sam/clients/build.sh
bash tests/integration/sam/run-independent.sh
```

The harness fails closed and emits sanitized run-specific evidence under
`target/interop/sam-evidence`. A manual unprivileged GitHub-hosted Ubuntu
`workflow_dispatch` job in `.github/workflows/sam-external.yml` runs the same
commands and uploads only that sanitized directory.
