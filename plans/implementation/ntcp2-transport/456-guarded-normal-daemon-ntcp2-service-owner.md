Status: **registered / ready — P0 parallel to Plan 455**. Date 2026-10-10. Owner: ntcp2-transport with daemon composition. Source baseline `58c364b6c1863f05747240de983b266380be0923`. Source corrective/precondition of Plan 435; distinct from full normal/public dual-transport qualification. Interface dependency: Plan 450 real `i2pr run` lifecycle passed, Plan 454 shared bandwidth governor passed; runtime-neutral NTCP2 state/handshake and `i2pr-runtime::Ntcp2RuntimeService` exist. **No hard dependency on stock-i2pd dial being initiated, Plan 451 SAM remote wiring, Plan 431 LAN, or Java.** No claim of interoperability is made by source compilation alone.

## Goal and classified result

Normal daemon `crates/i2pr-daemon/src/config.rs::normalize_ntcp2` unconditionally rejects `[transport.ntcp2] enabled=true` (Plan 101), and `lib.rs` does not register a supervised NTCP2 transport owner. Plan 454 added a dormant, properly accounted NTCP2 link adapter. Implement a **narrow, explicit, controlled-loopback qualification profile** for the real `i2pr run` binary so it can accept incoming authenticated NTCP2 and make outbound NTCP2 calls using **the same RouterIdentity/NetDB/I2NP dispatch** as SSU2, with no public binding, unsolicited advertisement or silent fallback to a second router core.

**Capability:** opt-in local controlled NTCP2 socket owner, not qualified public router service. **Infrastructure:** durable static X25519 key + NTCP2 IV lifecycle, runtime service registration and generic peer dispatch; **invariant:** Plan 101 disabled/default-fail-closed *outside the named qualification profile*, strict loopback, single governor and router process owner; **polish:** explicit operator test configuration and redacted health.

## Executable packages

1. Source audit: `crates/i2pr-daemon/src/{config.rs,lib.rs,router_i2np.rs,bootstrap.rs}`, `crates/i2pr-runtime/src/{ntcp2_runtime.rs,ntcp2_link.rs,bandwidth.rs,ssu2_runtime.rs}`, `crates/i2pr-transport-ntcp2/src/{crypto.rs,state_machine.rs}` (verify actual filenames), and existing persisted router/SSU2 store from Plan 442. Design one narrow transport manager/dispatcher handle; do not introduce a generic `Arc<RouterContext>`, second NetDB owner or runtime in a transport crate.
2. Add a distinct, opt-in **NTCP2 local qualification profile** to strict config parsing with `enabled=true` accepted **only** when profile explicitly names loopback and an operator-selected nonzero port. Preserve rejection of ordinary `enabled=true`, wildcard/public/private-LAN bind, implicit NTCP2 activation, unsolicited `R`/`f`/address publication and any old serialized config upgrade. All invalid settings must fail **before** creating keys/binding sockets. Extend Plan-101 negative static guards with mutation-tested named exception rather than removing them.
3. Persist NTCP2 static signing-associated key material and obfuscation IV in a versioned atomic owner bound to the *existing* RouterIdentity, with secure directory creation/0700, restrictive file permissions and rotation/restart semantics; no accidental router/destination key reuse. Create signed NTCP2 `RouterAddress` from the **actual listener endpoint** and static key/IV, with `v=2`, current `netId` and freshness. The signed address is available **only** to an explicitly provisioned test peer, not public NetDB. Wrong identity/static key/IV or socket endpoint must refuse startup; no ephemeral port placeholder.
4. Register `Ntcp2RuntimeService` and `AuthenticatedLink` under existing daemon supervision/cancellation with common bandwidth governor from Plan 454, inbound anti-abuse handshake limits, idle/write deadlines, per-peer queue bounds, zeroized material and bounded frame ownership. Inject authenticated inbound decoded I2NP to the **same daemon-owned NetDB/tunnel dispatch seam** used by SSU2, and select outbound peers via validated RouterInfo/transport policy, never a driver-only test bypass. Ensure sessions terminate on cancel and replacement without stranded tasks/sockets. Keep SSU2 live when NTCP2 fails.
5. Black-box test the actual `i2pr run --config` child process: identity generate, bind loopback TCP, programmatically verify signed NTCP2 `s`/`i`/port and RouterIdentity association, real session/admission vs ineligible/wrong network peer, shut down and restart with identical NTCP2 identity/IV, and disabled profile with **zero unexpected listeners**. Where controlled reference is accessible, invoke Plan 455 Gate A as a separate real peer check; do not falsely label local mock traffic as stock interop.
6. Add bounded negative/fault controls: reserved/private/wildcard binds, config omission, occupied TCP port, invalid key file/perms, RI identity mismatch, incomplete SessionConfirmed, malformed/unknown blocks, framed-byte limiter overflow, stalled handshake, disconnect while queued, repeated retry and transport-family isolation. Logs, metrics and snapshots use fixed categories only.
