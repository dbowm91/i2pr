## Work and acceptance

1. Design an explicit pair manifest/receipt schema covering **two independent locally invoked hosts**: expected role, identity digest, authorized RFC1918 network interface, current signed SSU2 address, listening UDP port, accepted stock binary SHA, phase and finite time budget. Reuse `plan472_live.py` `prepare/verify`, source-linked `scripts/plan449-ssu2-preflight.py`, and Plan 453 daemon config. Validate exact host assignment, signer/network ID, distinct identities/ports and non-reused process tokens. Never use IP alone as a trust identity.
2. Implement a constrained **local `run --live --role i2pr|i2pd`** owner on each machine. The local owner may start only the declared local `i2pr run` or unmodified pinned i2pd process with explicit 0700 temp state and pre-approved bind. Interhost data transfer is manual/owner-approved and authenticated; the executor **does not** SSH, discover peer addresses, relay over clearnet services, fetch public reseed or start a daemon on another machine. Reject missing consent, stale signed RI, changed interface/route, changed ports/identity, mismatched trusted peer artifact **before** opening any sockets or sending packets. Treat operator revocation as immediate cancellation/cleanup.
3. **Real product lane** (only on approved pair): establish live UDP SSU2 from both roles, correlate authenticated peer and session generation, independently prove both-direction I2NP request/reply with real NetDB/DeliveryStatus effect; prove source address matches both real interface and signed RI and stock correctly selects the i2pr peer. Recycle owner separately through stop/start with persisted SSU2 static/introduction key, replay/recovery, and signed endpoint withdrawal on disable or address/port change. Use bounded resource rates, one operator-authorized test window, no aggressive flood or unspecified host.
4. **Deterministic simulator/preflight matrix** (routine CI safe): never emit live packets. Unit-test 2-host manifest validation, denied/partial/revoked consent, wrong role/host/address/netmask, signature/hash key mismatch, wrong network, clock skew, renamed stale files, reference pin mismatch, socket failure, cancellation, child termination, missing peer receipt, mismatched run epoch/digests and empty external environment. Exercise phase transitions and per-host receipt reconciliation through an *in-process fake I/O adapter* that cannot connect, without claiming actual SSU2. `prepare` and `verify` remain non-emitting.
5. Evidence receipt remains fully sanitized: bounded phase/state/count, signed hash *digest of ephemeral receipt* but never raw key, full RouterInfo, actual private endpoint, external log or path; pair equality via owner-exchanged private artifact. Clear temporary secrets and reap all child processes. Successful real lane must require independent captures/receipts from **both** endpoints and exact pin—not just traffic observed from one host.
6. **Stop boundary:** do not execute live work here without actual supplied pair and explicit approval. After creating the executor, close **infrastructure-only** when simulator/test and fail-closed controls pass; live requirement stays blocked until operator executes. Never relax `run --live` fail-closed to make CI green or infer public conformance from local/LAN result.
