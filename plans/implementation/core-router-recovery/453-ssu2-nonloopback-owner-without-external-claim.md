# Plan 453 — Implement guarded non-loopback SSU2 owner without premature qualification

Status: **registered / ready** (2026-10-10). Owner: core-router-recovery (SSU2). Corrective to blocked Plan 431/442 **source implementation** boundary; Plan 449 already passed portable *offline preflight*, not live LAN. Hard dependencies: Plan 442 local persistent identity, Plan 440 qualification taxonomy. Plan 450/451 Gate A/B and Plan 452 NTCP2 are independent.

## Goal / separation of concerns

Implement an opt-in runtime-owned non-loopback SSU2 **socket, bound-address, persistent-key and signed RouterInfo lifecycle** under a **private-LAN qualification profile**; test address-policy and lifecycle deterministically on local hosts. Do not make production/source implementation conditional on acquiring two owner-approved LAN hosts, but **do not** close Plan 431's independent non-loopback interop, report public reachability, publish to production NetDB or set `R` based solely on local bind.

Classification: **infrastructure** = address/identity lifecycle and config; **capability** = optional controlled-LAN listener only after safety guards; **invariants** = default-off/public claim prohibited, explicit operator authorization, no link between router and destination identities; **polish** = operator qualified-lane instructions.

## Source grounded work

1. Inventory `crates/i2pr-daemon/src/config.rs::{parse_ssu2_bind,normalize_ssu2}` currently refusing non-loopback; `lib.rs::register_ssu2_service` currently hardcodes loopback RI and ephemeral `44001` placeholder, and `crates/i2pr-runtime/src/ssu2_runtime.rs` socket owner. Also read Plan 161 interop and Plan 449 preflight. Preserve the existing controlled loopback and default-disabled profiles as separate unchanged modes.
2. Define a **named, explicit and fail-closed** private-LAN qualification setting/permit. Non-loopback must require owner-supplied private local IP, explicit port, exact local interface/address ownership where possible, validated network ID, stored router/transport key pair, no public Internet bind, no wildcard, no general address-parser bypass. Reject a non-local address, IPv6/unapproved address family, unauthorized profile, changing router identity, mismatched publish/bind or stale invalid key material **before** binding. Do not implement an always-on `allow_local` that propagates into production peer selection.
3. Make the runtime SSU2 socket report the **actual bound address and port** to daemon composition before generating/signing the local controlled RouterInfo; remove any reliance on test-only `44001` placeholder for records consumed by other processes. Ensure identical persisted `s` and `i` across restart; treat bind changes/port changes as explicit re-sign events, not key rotation. Retain precise `netId` and expiry validation and bounded authenticated delivery.
4. Separate three outputs: (a) private test-visible signed RouterInfo with locally owned private endpoint, (b) externally distributable public RouterInfo **not authorized in this plan**, and (c) positive reachability/capability permit **not minted** here. The existing `advertise=false`, no-`R`, no-introducer and no-`f` defaults remain. Controlled peer provisioning may pass a verified RI out-of-band in an authorized lab, not publish it to public NetDB.
5. Add local deterministic config tests and socket-backed same-host/private-interface tests only where the environment is explicitly available, with tests skipped **only by an explicit ignored external lane** that fails when deliberately invoked without required inventory. Verify negative controls: wrong bind/address/port/network ID, identity rotation, key corruption, address-claim mismatch, shutdown and restart. An authorized real two-host RFC1918 i2pd+ i2pr bidirectional authenticated I2NP test remains a separate **Plan 431 / Plan 449 live qualification gate**.
6. Explicitly document how an operator supplies the Plan 449 inventory, obtains independent evidence, and disables the private-LAN profile after test. No public auto-discovery or UPnP/NAT integration in this plan.
