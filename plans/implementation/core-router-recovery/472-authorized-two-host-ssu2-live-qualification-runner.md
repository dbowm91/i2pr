2. Implement portable local **per-host** prepare/verify/run commands: no remote SSH or host agent is launched by default. Preflight has **no packet emission**; the live flag must be separate, explicit, and present on **both** hosts.
3. Execute finite pair: i2pr normal guarded private-LAN SSU2 vs pristine stock i2pd. Observe actual address-distinct UDP packet/session authentication and real I2NP/DeliveryStatus in **both** initiated roles with signed peer attribution; test restart retaining valid static/intro identity and withdrawal/update after listener port/address or reachability loss. Preserve safe process lifecycle and isolate local state. A private LAN is **not** public Internet reachability, NAT traversal, introducer service, Java family or production anonymity.

Negative controls: unauthorized/missing consent, host unknown, same endpoint, non-private address, mismatched subnet, stale RouterInfo, changed static/intro key, wrong network ID, replay/cancel/queue saturation, no route, port conflict and session restart. Active network abuse/dos testing is forbidden on shared LAN; simulate high-risk malformed traffic in unit tests only. All child/service cleanup bounded; machine-specific values transient under private 0700 directories.
5. Add pure deterministic self-tests for manifest validation, consent/identity/family/endpoint mismatch, receipt parser, phase progression and failure cleanup. Routine CI runs **no live network**; deliberately invoked live mode without supplied authorized pair fails with `environment-unavailable`, never silently succeeds. Live evidence only under approved operator execution; a missing external environment does not block 470, 471 or 473.
