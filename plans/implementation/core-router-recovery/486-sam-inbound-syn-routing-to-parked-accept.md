## Concrete source-boundary discrepancy

A SAM destination bridge owns two `StreamingManager` instances — canonical (`bridge.streaming()`) and receiver mirror (`bridge.receiver_streaming()`) — and the lane's reverse leg wires them oppositely. Inbound garlic drains route whole-destination by `is_server` (`sam/streams.rs:1417-1433`); the lane destination is staged `GenericClient` (`service_tunnels.rs:1141`), which `spec_is_server` maps to false (`service_tunnels.rs:4321-4333`), so inbound SYNs feed the **canonical** manager, which holds no listener. `STREAM ACCEPT` binds wildcard-0 and polls backlog/`accept()` on the **mirror** (`sam.rs:4246-4255`, `4438-4452`), which is never fed. Proof it is instance mismatch and not timing: a manager with wildcard-0 bound can never emit `no_listener` (exact-or-wildcard match, `streaming/manager.rs:1210-1221`), so both `no_listener` rejections necessarily came from canonical while the mirror's wildcard sat idle — the waiter polls an ever-empty backlog and the 20 s expiry is structural, not short. The forward leg works because canonical owns the outbound SYN state (Plan 213's design intent), which also explains the directional asymmetry with no stock behavior implicated. Stock's 10 retries prove the wire, garlic, and LeaseSet (ordinary type-3, i2pd-consumable) all function; lengthening the ACCEPT wait or hunting transit loss cannot establish this leg.

**Capability:** a parked `STREAM ACCEPT` on a STREAM-session destination establishes when a valid inbound SYN arrives — the SYN reaches the waiting instance's backlog and the waiter converts it to Established. **Infrastructure:** waiter-scoped dispatch routing + stale-backlog age eviction + per-instance receipt split. **Invariant:** loopback-only, exact-pinned unmodified stock references, sanitized counts-only receipts, silent rejection on every path (no distinct remotely observable response per cause — stated invariant, not assumption), fail-closed dispatch/teardown, no support/capability/advertisement change, `max_sessions` and `max_listener_backlog` bounds unchanged, no new loopback listeners.

## Considered and rejected (do not resurrect without new evidence)

- **Always feed mirror for STREAM destinations with packet-type split:** puts SYN classification in the hot dispatch path and the working forward leg (SYN-ACK/DATA must still reach canonical) inside the blast radius; widens unsolicited backlog accumulation to any-time. Generality the lane does not need.
- **Bind the ACCEPT listener on canonical:** 2-line bind, but the accepted connection would live on canonical while every Inbound pump consumer reads mirror (`raw_stream.rs:303-312,524,658,741`; `service_tunnels.rs:7353,7508,7525`) — requires pump re-thread, connection migration, or dual-poll, i.e. the largest audit surface, risking the working forward DATA path through shared pump code.
- **Flip the spec kind to server profile:** enrolls SAM destinations in server machinery (staging listener binds, server accept loops, profile-conditional loopback-listener requirements) — new loopback attack surface and a lifecycle (485 control-socket gating) never qualified against it. A dispatch-only profile override is just candidate (a) renamed and lives inside WP2.
- **Lengthen the ACCEPT wait / hunt transit loss / ELS2 work:** structurally incapable (backlog stays 0 forever), demoted by evidence, out of scope respectively.

2. **Waiter-scoped SYN routing.** In the dispatch seam, route inbound SYN packets for a STREAM-session destination to the receiver mirror iff an ACCEPT waiter is parked for that destination (registry query); every other packet keeps profile routing. Constraints: SYN classification must be bounded and must not alter the garlic/auth path (name the mechanism — single-decode pass or bounded header peek — in code comments); concurrent forward-leg DATA during a park window must still reach canonical (WP1 guard enforces); SYN arriving before any park still dies on canonical (accepted residual, today's behavior). Document the lock acquisition order (stream registry vs `sam_destinations` vs bridge) at the seam; deadlock review is a closure requirement.
3. **Stale-backlog age eviction in `StreamingManager`.** `accept()` is a bare FIFO pop with no expiry; waiter timeouts already orphan entries today. Add bounded age-based eviction (config-constant TTL, streaming-clock ms), a counts-only evicted counter, and unit tests (eviction fires, live entries survive, cap still enforced). No unbounded growth argument may rely on session teardown alone.
4. **Per-instance receipt split.** The summed 8-tuple concealed a total instance miss for a full turn. Extend the ACCEPT-SYN expiry receipt (WARN + TIMEOUT reply) with canonical-vs-mirror columns, require them in the lane parser (summed-only legacy shape refused), extend the offline receipt tests, probe-kill by dropping one instance's columns. This receipt change is the material change licensing the WP7 lane.
5. **Silent-drop invariant (negative).** Manager-level test: no outbound packet queued after any reject path (decode/validation/signature/no-listener/backlog-full/evicted) — `drain_outbound` empty in each case; adapter `Err` mapping unchanged. This is the no-remote-oracle evidence.
6. **Regression matrix.** Dispatch matrix (profile × waiter-parked × packet type: SYN / SYN-ACK / DATA / datagram) all green; waiter lifecycle (park → claim → release; timeout → eviction; double-park contention semantics stated); concurrent CONNECT + parked ACCEPT on one destination (DATA still canonical, SYN still mirror); `destination_tunnel_unit`, `sam_stream_self_composed`, `sam_stream_final_acceptance` green (pump untouched — prove it).
